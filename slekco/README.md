# Slekco - Premium Minimalist E-Commerce Platform

Slekco is a modern, high-performance, and visually stunning e-commerce platform built around the philosophies of minimalism, sustainability, and wabi-sabi. Designed with an editorial, luxury aesthetic, it provides users with an effortless shopping experience.

## ✨ Features

- **Premium UI/UX:** A serene, sophisticated design featuring beautiful typography, subtle animations, and curated custom lifestyle photography.
- **Responsive Layout:** Flawless experience across desktop, tablet, and mobile devices.
- **Product Filtering & Categories:** Browse products by categories (Home, Accessories, Fragrance, Wellness) or partner brands (Atelier, Lumina, Aethel, Kinto, Void, Aura).
- **Wishlist Functionality:** Save your favorite items seamlessly with Redux state management.
- **Cart Management:** Real-time cart calculations and a beautifully designed checkout flow.
- **Dedicated Brand & Collection Pages:** Immersive pages detailing brand philosophies and curated lookbooks.

## 🛠 Tech Stack

**Frontend:**
- React (Vite)
- Redux Toolkit (State Management)
- Tailwind CSS (Styling)
- Framer Motion (Animations)
- React Router DOM (Navigation)
- Lucide React (Icons)

**Backend:**
- Node.js
- Express.js
- Custom Mock Data Engine (Replaceable with MongoDB)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/slekco.git
   cd slekco
   ```

2. **Install Backend Dependencies:**
   ```bash
   cd server
   npm install
   ```

3. **Install Frontend Dependencies:**
   ```bash
   cd ../client
   npm install
   ```

### Running Locally

1. **Start the backend server:**
   ```bash
   cd server
   npm run dev
   ```
   *The server will run on http://localhost:5000*

2. **Start the frontend application:**
   ```bash
   cd client
   npm run dev
   ```
   *The application will be accessible at http://localhost:5173*

## 🎨 Design Philosophy
Slekco draws deep inspiration from Japanese *Wabi-Sabi*—finding beauty in imperfection—combined with modern minimalist principles. The application utilizes a muted color palette (`#F7F5F0` surface, `#2A2A2A` primary text, `#8C867D` secondary text) and high-quality editorial imagery to create a calming, premium shopping environment.
